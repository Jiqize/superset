# Phase 4C safe evidence

This directory contains sanitized paired visual and acceptance evidence for
the controlled AA Office v0.2 refinement on the original development Mac.

The QA inventory was fixed before implementation. Baseline and final evidence
use the same repository-managed `phase-4c` profile, disposable local Git
Briefcase, route/state, and logical viewport wherever practical. Raw terminal
transcripts, personal paths, credentials, account data, and transport IDs are
not evidence.

## Index

- `QA-INVENTORY.md` — acceptance inventory fixed before implementation.
- `VISUAL-PUNCH-LIST.md` — reproducible baseline findings and authorized scope.
- `ROUTE-MATRIX.md` — paired before/after surface coverage.
- `ACCEPTANCE-RESULTS.md` — real single-machine interaction results.
- `DENSITY-MEASUREMENTS.json` — repeatable 1440×800 geometry measurements.
- `ACCESSIBILITY-MOTION.json` — File Cabinet keyboard/ARIA and reduced-motion
  probes.
- `RESTART-RESUME.json` — sanitized full-restart and exact-resume result.
- `screenshots/` — normalized, metadata-stripped product evidence. Terminal
  transcripts, absolute paths, and raw identifiers are masked.
