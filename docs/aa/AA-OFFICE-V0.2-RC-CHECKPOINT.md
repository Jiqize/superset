# AA Office v0.2 RC checkpoint

## Verdict

`AA OFFICE V0.2 RC READY WITH ACCEPTED DEBT`

development Mac. One AA application shell and shared page-body language now

## Frozen product contract

- Pi is the fixed first `PRIMARY` Employee and is sourced from the real Host Pi
  configuration, not a synthetic or reorderable preset row.
- `NEW TASK` remains the primary daily project-local action and launches one
  real isolated Work Folder plus one real Pi conversation.
- Active Tasks remains a read-only projection over real workspace, pane,
  Runtime, resume, archive, and Git evidence.
- `LIVE` requires current Tier 1 Runtime Contract evidence.
- `SAVED / RESUMABLE` requires an exact Host resume candidate.
- Compatibility Employees launch through existing presets and remain
  `UNTRACKED` without Tier 1 authority.
- Archive/Unarchive changes only durable organization intent; it does not stop,
  delete, complete, reset, or clean work.
- Work Folder and Task Folder remain presentation over the accepted Superset
  workspace/pane models; no AA task database exists.
- Exact Pi resume preserves native session identity and creates a new runtime
  epoch.
- Real xterm, terminal focus/input, Files, Changes, Diff, Review, Git, branches,
  worktrees, and pane persistence remain unchanged.
