# Phase 3D Safe Evidence

This directory contains curated evidence for the isolated AA Tier 1 Agent
Experience acceptance. Screenshots use a 1440×800 logical viewport and contain
only disposable AA project data plus deliberately harmless verification text.
No credential, token, environment dump, production source, or raw Pi runtime
identity is retained.

## Machine-readable evidence

`pi-exact-resume-evidence.json` records the before/after contract projection.
The matching native conversation and changed epoch are represented by
12-character SHA-256 fingerprints. It contains no raw native session UUID,
epoch, workspace/terminal ID, prompt, transcript, tool body, or credential.

The disposable project, workspace, worktree, terminals, QA profile, and local
listeners were removed after capture. The source fixture was moved to the
macOS Trash rather than permanently erased.
