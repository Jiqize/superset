# AA Office v0.2 debt register

This register contains accepted debt observed while completing the original-Mac
v0.2 release candidate. None is hidden behind a false RC claim. `P1` would block
normal daily correctness; `P2` affects usability/diagnostics but has a safe
workaround; `P3` is polish or development-environment debt.

## Release decision

There are no open `P1` items. The v0.2 verdict is therefore:

`AA OFFICE V0.2 RC READY WITH ACCEPTED DEBT`

## Explicitly not debt in v0.2

- Pi is the fixed first Employee and remains Tier 1.
- Compatibility Employees truthfully remain `UNTRACKED`.
- Offline is not Live, and resumability requires an exact Host candidate.
- Archive is organization intent, not Done or deletion.
- The real terminal, Files, Changes, Diff, Review, Git, worktree, and exact Pi
  resume contracts remain the accepted implementation.
- Packaging, signing, notarization, tagging, cross-device sync, and a second-Mac
  update were intentionally excluded rather than left half-implemented.
